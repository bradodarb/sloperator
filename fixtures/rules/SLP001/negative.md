Plain wording stays as it is, and a utilization report is not a verb.

Use `utilize` and `in order to` in code spans, and `leverage` too.

```text
We utilize the cache in order to leverage it and delve into the logs.
```

See [the guide](https://example.com/utilize/leverage-in-order-to) for details.
